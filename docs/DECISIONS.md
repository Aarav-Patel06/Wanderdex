# Decisions

Choices made where `docs/SPEC.md` is silent (SPEC §0). Newest at the bottom.

| Date | Decision | Reason |
|---|---|---|
| 2026-09-28 | Installed pnpm with `npm install -g pnpm` (v12.6.0). | pnpm wasn't installed. A user-level npm install needs no admin rights (`corepack enable` writes into Program Files). Owner approved. |
| 2026-09-28 | Scaffolded with `create-next-app` into a temp folder, then copied only config files, `src/`, and the lockfile into the repo. Skipped the boilerplate `public/*.svg` and `README.md`. | The repo wasn't empty. The boilerplate assets are unused, and the README is a Phase 3 task. |
| 2026-09-28 | Kept the `AGENTS.md` generated by Next.js 16 and imported it from `CLAUDE.md` (`@AGENTS.md`). | `next dev` recreates it anyway. It points agents to the bundled Next 16 docs. While AGENTS.md exists, Next leaves CLAUDE.md alone. |
| 2026-09-28 | Merged the existing generic CLAUDE.md guidelines into the new, shorter project CLAUDE.md. | Owner chose "merge, condensed". |
| 2026-09-28 | Tailwind CSS v4, configured in CSS (`@theme` in `src/styles/globals.css`); there is no `tailwind.config`. | This is what current `create-next-app` and shadcn generate. |
| 2026-09-28 | Moved the global stylesheet from `src/app/globals.css` to `src/styles/globals.css` and pointed `components.json` at it. | Matches SPEC §6. |
| 2026-09-28 | Ran `shadcn init` with the Radix base and the "Nova" preset. | 8bitcn components wrap Radix-based shadcn components (`asChild`, Radix Dialog/Select). The preset only affects defaults that are overridden by our tokens anyway. |
| 2026-09-28 | Kept `shadcn`, `cn`, `radix-ui`, `class-variance-authority`, and `tw-animate-css` as dependencies. | The shadcn CLI installs them as part of shadcn/ui (SPEC §4). `cn` is shadcn's replacement for clsx + tailwind-merge. `shadcn` provides `shadcn/tailwind.css`. |
| 2026-09-28 | Added `"@8bitcn": "https://www.8bitcn.com/r/{name}.json"` under `registries` in `components.json`. | 8bitcn is also in shadcn's built-in directory. The explicit entry documents where components come from. |
| 2026-09-28 | Removed `next-themes` and `lucide-react`. `ui/sonner.tsx` uses a fixed light theme; `ui/dialog.tsx` and `ui/select.tsx` use Pixelarticons (Close, Check, ChevronDown, ChevronUp). | Neither is in SPEC §4, there is no dark mode, and Pixelarticons is the icon set. Owner approved. `components.json` still says `iconLibrary: "lucide"` because shadcn has no Pixelarticons option, so icons must be swapped after each future `shadcn add`. |
| 2026-09-28 | Spec tokens reuse the shadcn variable names where they match (`--background`, `--primary`, `--accent`). Other shadcn variables point at tokens (`--foreground` → `--text`, `--card` → `--surface`, `--destructive` → `--error`, `--border` → `--text`, `--ring` → `--accent`, `--muted` → `--surface-dark`). | One definition per color. As a result, shadcn's hover/highlight `bg-accent` is orange; dark text on accent is about 5:1. |
| 2026-09-28 | Kept `@custom-variant dark (&:is(.dark *))` but deleted the `.dark` color block and the chart/sidebar variables. | Without it, Tailwind v4's `dark:` follows the OS setting and would restyle the 8bitcn components. `.dark` is never applied, so `dark:` classes never take effect. |
| 2026-09-28 | Type scale utilities: `text-h1`, `text-h2`, `text-h3`, `text-button`, `text-body`, `text-small`, `text-tiny`. Font utilities: `font-display` (Press Start 2P) and `font-body` (VT323), plus `font-heading` for shadcn. | Named after SPEC §16.4. |
| 2026-09-28 | Configured `cn` in `src/lib/utils.ts` to recognize the custom size, font, and shadow utilities, and switched the base shadcn components from importing the `cn` package to `@/lib/utils`. | Otherwise `cn` treats `text-button` as a color and silently drops `text-primary-foreground` (verified). |
| 2026-09-28 | Two offset shadow tokens: `shadow-pixel` (box-shadow) and `drop-shadow-pixel` (filter), both `4px 4px 0 var(--text)`. 8bitcn buttons and cards use `drop-shadow-pixel`. | 8bitcn draws its pixel border outside the element box, which would hide a box-shadow. The drop-shadow filter follows the notched border. |
| 2026-09-28 | Square corners come from `--radius: 0` plus every `--radius-*` theme size pointed at it. | 8bitcn and shadcn classes such as `rounded-lg` then produce 0 without editing each component. |
| 2026-09-28 | The global `:focus-visible` outline (4px accent) sits outside any cascade layer. | Unlayered CSS beats Tailwind's `outline-none` utilities in the shadcn components, so the focus style is the same everywhere. |
| 2026-09-28 | Removed the Google Fonts `@import` from 8bitcn's `retro.css`; `.retro` uses `var(--font-press-start)` from next/font. Moved `.pixelated` into `globals.css` as a Tailwind `@utility`. | SPEC §4 says fonts load with `next/font/google`. That avoids loading the same font twice and an external stylesheet request. |
| 2026-09-28 | 8bitcn components default to the body font (VT323) for input, label, select, card body, and alert text. Button, card title, and dialog title keep Press Start 2P (`retro`). | SPEC §16.4: VT323 for body, inputs, and labels; Press Start 2P for headings and buttons. |
| 2026-09-28 | Wired 8bitcn's own `buttonVariants` and `alertVariants` into their components; they were defined but never applied. Replaced the unused button variant values with token-based ones. | This was needed to add the ghost style and the alert `warning`/`error` variants. |
| 2026-09-28 | In 8bitcn `card.tsx` and `dialog.tsx`, moved `{...props}` before `className`. | Previously a caller's `className` replaced the component's own classes, including the H3 title style. |
| 2026-09-28 | Typed 8bitcn `DialogContent` props as shadcn `DialogContent` props instead of plain `div` props. | Needed to pass `showCloseButton={false}` from the RPG dialog. |
| 2026-09-28 | Repointed type imports in 8bitcn `label.tsx`/`select.tsx` from `@radix-ui/react-*` to the `radix-ui` package. | The shadcn CLI installs only the `radix-ui` umbrella package, so the old imports would fail type-checking. |
| 2026-09-28 | Toast API: `toast(title, { description?, variant?: "default" \| "success" \| "visited" })`. Title VT323 20px, description VT323 18px. Close button is 44px. The Toaster sits top-center with a 4000 ms duration. | SPEC §16.6 and §16.8. Top-center keeps toasts clear of the bottom add panel and tab bar coming later. VT323 because 16px Press Start 2P titles wrap badly at 375px. |
| 2026-09-28 | Alerts have no close (×) button, although the sheet shows one. | SPEC §16.6 doesn't ask for dismissible alerts. |
| 2026-09-28 | Replaced the dialog overlay's `bg-black/10` + blur with `bg-text/60` and no blur. | No hard-coded colors (SPEC §16.2). Blur isn't pixel-style. |
| 2026-09-28 | RPG dialog (`src/components/dialogs/rpg-dialog.tsx`) is built on the 8bitcn/Radix Dialog. Radix provides the focus trap, Escape to close, and focus on the first choice when it opens. Arrow Up/Down (wrapping) and Home/End move between choices; Enter/Space selects. The caller closes the dialog in `onSelect`. | Full keyboard support with the least custom code. Callers control closing so async actions like logout can keep the dialog open. |
| 2026-09-28 | The "▶" marker is written as `▶︎` (text-presentation selector). | Stops iOS from drawing it as an emoji. |
| 2026-09-28 | Favicon: `src/app/icon.png` is a byte-for-byte copy of `public/sprites/passport.png`; the default `favicon.ico` is deleted. | App Router icon convention (SPEC §16.7). No resampling (verified by file hash). |
| 2026-09-28 | Removed `antialiased` from `<html>`. | Font smoothing blurs and thins pixel fonts. |
| 2026-09-28 | `.gitignore` keeps `.env*` and adds `!.env.example`. | Otherwise `.env.example` would be ignored and never committed. |
| 2026-09-28 | Vitest runs in the node environment with an `@` → `src` alias, no plugins. The `test` script is `vitest run --passWithNoTests`. | The upcoming tests (SPEC §19) are pure logic. Without the flag, Vitest fails when there are no test files. |
| 2026-09-28 | Sprites render with `next/image` `unoptimized` plus `.pixelated`. | The image optimizer would resample the pixel art. |
| 2026-09-28 | Temporary component preview lives at `src/app/page.tsx`, not `(app)/page.tsx`. | Throwaway page, to be replaced by the Overworld in the next step. |
